# GitHub Profile Finder 🚀

A sleek and interactive web application to search and explore GitHub user profiles effortlessly. Discover user details, followers, repositories, and more with a beautiful, animated UI!

## ✨ Features

- 🔍 **Search Users**: Enter a GitHub username to fetch and display profile information.
- 👤 **Profile Display**: View avatar, bio, followers, following, and public repositories.
- 📂 **Top Repositories**: Shows the top 10 starred repositories for each user.
- 🔗 **Social Links**: Quick access to your GitHub and Instagram profiles.
- 🎨 **Modern UI**: Gradient backgrounds, animations, and responsive design.
- ⚡ **Fast & Lightweight**: Built with vanilla JavaScript and CSS for optimal performance.

## 🚀 How to Use

1. **Clone or Download** the repository.
2. **Open** `index.html` in your web browser.
3. **Search** for a GitHub username in the input field.
4. **Explore** the profile card with user details and repositories.
5. **Click** on links to view profiles or repos on GitHub.

## 🛠️ Technologies Used

- **HTML5**: Structure and layout.
- **CSS3**: Styling with animations and gradients.
- **JavaScript (ES6)**: Fetching data from GitHub API.
- **GitHub API**: For retrieving user and repository data.
